# Prepare evidence

Prepared 2026-09-26. The fixed corpus contains 120 distinct 3-SAT formulas: 20 hand cases and 100 seeded random cases, with 64 YES and 56 NO. Formula sizes range from 0 to 6 variables. `generate_cases.py` fixes inputs and seeds before any candidate construction.

Run `uv sync --locked` and `uv run --locked python campaigns/elastic-degenerate-inequivalence/work/check.py --self-test`. It first runs the copied `research/validate_preparation.py`, regenerates every random formula, recomputes its Z3 label, validates assignments directly, and crosschecks with exhaustive Boolean assignments. Target equality is decided by complete finite-language expansion: iterative concatenation into a set of words. A separately written Cartesian-product enumerator agreed on 120 seeded target pairs. The direct witness validator uses dynamic string-position membership rather than language expansion; it agreed with enumerated membership, including empty words and empty option sets. Only Z3 `unsat` yields a negative source result; `unknown` raises. An intentionally incorrect candidate returning distinct one-word languages and always extracting NO-SOLUTION was rejected.

Oracle: CPython 3.12.14 and locked `z3-solver` 4.16.0.0. The target expansion can be exponential in the number of option sets; this Prepare foundation is for finite small instances and is not a polynomial-time language-equivalence algorithm. The candidate gate inspects up to three target words per instance, not every symmetric-difference word. No reduction or solution is claimed; zero construction rounds were authorized for this setup.
